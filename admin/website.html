First-run setup

This preview build has no backend yet, so administrator access is provisioned locally: the first signed-in account to claim ownership becomes the site administrator, and the claim is closed afterwards. In production, administrator roles must be granted and every admin operation must be authorized server-side.

Featured content

Announcement

Prototype note: featured content and announcements are stored in the data layer. The public homepage will consume these settings when the public pages are wired to it — public pages are not modified in this task.

Homepage sections

Reorder or hide the homepage sections. Like the featured content, this takes effect on the public homepage once it is wired to the data layer.

Telefon bildirimleri (Web Push)

Yeni bölüm yayınlanınca okuyucuların telefonuna bildirim gider (iOS 16.4+ ve okuyucunun siteyi Ana Ekrana eklemiş olması gerekir).

Şimdi Edge Function'ı kur: Supabase → Edge Functions → Create a new function → adı notify-new-chapter olsun → aşağıdaki kodu yapıştır → Deploy.
