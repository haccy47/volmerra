First-run setup

This preview build has no backend yet, so administrator access is provisioned locally: the first signed-in account to claim ownership becomes the site administrator, and the claim is closed afterwards. In production, administrator roles must be granted and every admin operation must be authorized server-side.

All seasons

Visibility rules: content of unreleased and coming-soon seasons is filtered out at the data layer, so it never reaches the public pages — chapters, characters and their portraits, locations, lore and gallery entries all respect their season's status. The public theme automatically follows the latest published season; previews here apply to your admin view only. S1 ships published by default so existing content stays visible — change it above if needed. While the website is open, scheduled seasons release automatically at their time; reliable release when nobody has the site open requires a server-side scheduler.
